# Dạo Phố Cổ

Game mô phỏng đời sống phố cổ Hà Nội: dạo phố, làm thêm ở quán phở, quán cà phê, đi xe máy, thăm Văn Miếu, Hồ Gươm, câu cá bãi sông Hồng, làm nông trại ở Làng Rau Bãi Giữa.

Chơi ngay: https://lehoangnam206.github.io/dao-pho-co/

- Máy tính: mũi tên / WASD để đi, E để tương tác, M bản đồ, B túi đồ, P điện thoại.
- Điện thoại: cầm ngang máy, kéo cần gạt bên trái để đi, bấm nút đỏ bên phải để tương tác. Mở bằng Safari/Chrome rồi "Thêm vào màn hình chính" để chơi toàn màn hình.

Kho này chỉ chứa bản build để chạy trên web.
